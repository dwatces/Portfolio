Case study · Guided tour operator, Dunedin

A dated tour site, rebuilt to take bookings and keep most of its old links working.

By Daniel Olliver · Published 8 July 2026 · Updated 20 October 2026

Back to Nature Tours has run guided trips around the Otago Peninsula since 1997. Its website had fallen behind, so I rebuilt it from the ground up into a site the owner can update himself, with FareHarbor booking on every tour page and most of the old page addresses kept or redirected.

Where it started

Back to Nature Tours had been showing people the wildlife and landscapes of the Otago Peninsula since 1997, but the website hadn’t kept pace. It was a dated FareHarbor-hosted WordPress site, and small updates were enough of a wrestle that the site mostly went untouched.

What I built

Rather than swap one template for another, I redesigned the site from the ground up — a full custom design, rebuilt on Webflow CMS so the owner can edit it himself. It follows the same controlled process I use for a business website redesign: keep what has earned trust, replace what is holding the site back, and plan the migration before launch. The same person does every part of it — see who you are dealing with.

  • A full custom redesign, not a template swap, laid out for the phones most visitors are using.
  • A client-editable Webflow CMS, where Tours and Testimonials are their own collections, so the owner can add and update content himself without touching the layout.
  • FareHarbor booking carried across from the old site and re-integrated into the new CMS, so every tour page opens the right booking for that tour.
  • An SEO migration: the main page addresses kept, 301 redirects for most of the rest, and structured data set up on the new site for the business, each tour and the FAQ page, so old links and search results mostly lead to a working page instead of a dead end. I’ve written up how that kind of move protects rankings if you’re weighing up a rebuild of your own.

Custom design · Webflow CMS · FareHarbor booking · SEO migration · Structured data

The result

The owner can update the site himself, and bookings run through FareHarbor from each tour page. Because the migration kept the main page addresses and redirected most of the rest, old links and search results mostly still lead somewhere useful.
