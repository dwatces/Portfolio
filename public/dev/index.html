Earlier builds

Three full-stack apps I built myself.

My own projects, not client work. I built them in 2021, then modernised and redeployed them on Vercel in 2026, so each one is live to click through.

More of my code on GitHub ↗

  • scenic-app.vercel.app

    My own build · 2021, modernised 2026

    Scenic

    React · Express · MongoDB Atlas · JWT

    An image-sharing app: accounts, photo posts with each place on a map, member pages and a community feed. Its React client and Express API both run on Vercel, the API as serverless functions. In 2026 I moved the client to Vite and added API, component and end-to-end tests, with automated accessibility checks.

    Live site ↗: ScenicCode ↗: Scenic

  • nz-camps.vercel.app

    My own build · 2021, modernised 2026

    NZ Camps

    Express · EJS · MongoDB · Passport

    A campground review platform for New Zealand: accounts, campground CRUD, reviews, search, and locations geocoded onto maps. It’s server-rendered with EJS and runs serverless on Vercel. In 2026 I tightened its security and added integration and end-to-end tests, with automated accessibility checks.

    Live site ↗: NZ CampsCode ↗: NZ Camps

  • eon-ht82.vercel.app

    My own build · 2021, modernised 2026

    Eon Candles

    Next.js · React · Stripe

    A brand and shop site for Eon, a New Zealand candle label: a shop, product pages and a cart, with checkout priced on the server. It runs on Vercel, and the live site takes no payment. In 2026 I upgraded Next.js and React, and added unit, API and end-to-end tests, with automated accessibility checks.
